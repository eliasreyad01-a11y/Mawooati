# نظام التصميم

| الرمز | القيمة | الاستخدام |
|---|---|---|
| greenDark | #1B6B34 | الشعار، العناوين، الأيقونات الرئيسية |
| green | #2E9E4F | الأساسي، شريط الميزانية |
| greenLeaf | #7CC77A | ورقة الشعار الصغيرة |
| greenSoft | #E8F5E3 | بطاقة الترحيب، خلفية البداية |
| greenMist | #CFE9C9 | تدرج الترويسة |
| background | #F4F6F4 | خلفية الشاشات |
| warning | #F29D38 | شريط الميزانية ≥ 80% |
| danger | #D64545 | تجاوز الميزانية |

- الخط: Cairo (مضمّن، OFL). الأوزان 400/600/800.
- الزوايا: بطاقات 20، أزرار 14. الحد الأدنى للمس 48dp.
- الحركة: 120ms (ضغط) / 280ms (انتقال) / 350ms (ظهور) / 2.4s (البداية). لا حركات متكررة.
- تقليل الحركة: من إعداد التطبيق أو النظام؛ يُلغي الانتقالات والظهور المتحرك ويُقصّر البداية إلى 0.4s.
- العملة: JOD تُعرض "د.أ" بأرقام لاتينية.
