# تقرير المرحلة 2: الحسابات وقاعدة البيانات

## ما أُنجز
- **قاعدة البيانات** (`supabase/migrations/0001_core.sql`): profiles, households, household_members, household_invites, storage_locations, categories, products, product_batches, stock_movements.
- **الأمان RLS** على كل الجداول؛ أدوار owner/admin/member/viewer تُفرض من قاعدة البيانات.
  - المشاهد يقرأ فقط. العضو يكتب. المدير والمالك يديران. الدعوة بدور مالك ممنوعة. لا يمكن إزالة آخر مالك.
  - مفاتيح مركبة (id, household_id) تمنع ربط صف بمنزل آخر.
  - سجل الحركة للإضافة فقط. anon لا يصل لأي جدول.
  - دوال RPC: `create_household` (تنشئ المنزل والعضوية وأماكن تخزين وتصنيفات افتراضية، بحد 5 منازل) و`accept_invite` (تتحقق من البريد والصلاحية وعدم إعادة الاستخدام).
- **جاهزية المزامنة**: UUID، `updated_at`، حذف ناعم، `created_by` يصبح null عند حذف الحساب فتبقى البيانات للعائلة.
- **Flutter**: تسجيل الدخول، إنشاء حساب (مع تأكيد البريد)، استعادة كلمة المرور (إرسال الرابط)، إعداد المنزل، شاشة تحميل مع إعادة المحاولة، تسجيل الخروج من الإعدادات.
- **التوجيه**: `SessionGate` يوجّه حسب الحالة (دخول ← إعداد منزل ← رئيسية) ويعيد التوجيه عند الخروج.
- رسائل أخطاء عربية للأخطاء المعروفة وللانقطاع عن الشبكة.
- الإعدادات لا تُخزَّن في الكود: `--dart-define`.

## ما اختُبر فعلاً
- **SQL**: الترحيل واختبارات RLS (`supabase/tests/rls_test.sql`) نُفّذت على **PostgreSQL 16 حقيقي** ونجحت كلها (عزل المنازل، منع الكتابة للمشاهد، الدعوات، آخر مالك، anon، السلامة المرجعية، حذف الحساب).
  - **قيد:** مخطط `auth` كان مُحاكى بنسخة مبسّطة (`auth.uid()` و`auth.jwt()`) لا Supabase نفسه. يلزم تشغيلها مرة على مشروعك الحقيقي.
  - اكتشف الاختبار خللاً (حذف حساب يفشل بسبب `created_by`) وأُصلح.
- **Dart**: لم يُترجم ولم تُشغَّل اختباراته (لا SDK هنا). فُحصت الأقواس والاستيرادات فقط. كُتب 9 اختبارات واجهة (تحويل الدخول/الإعداد/الرئيسية، أخطاء الدخول، تحقق المدخلات) بمستودعات وهمية.

## لم يُختبر ولا يمكن اختباره هنا
- الاتصال الحي بـ Supabase (دخول، تسجيل، إرسال بريد، RPC).
- وصول رسالة تأكيد البريد (تعتمد على إعداد البريد في Supabase؛ الباقة المجانية لها حد إرسال منخفض).

## حدود معروفة (قرارات مؤجلة)
- **إعادة تعيين كلمة المرور داخل التطبيق** تحتاج Deep Links: حالياً يُرسَل الرابط فقط (المرحلة 8).
- **حذف حساب مالك منزل فيه أعضاء** يترك المنزل بلا مالك. يجب تصميم "نقل الملكية" قبل إتاحة حذف الحساب من التطبيق (المرحلة 8).
- Google/Apple Sign-In مؤجّل.
- دعوة الأعضاء: الجداول والصلاحيات جاهزة؛ شاشاتها في المرحلة 8.

## خدمات خارجية
Supabase (مجاني للبداية). لا مفاتيح سرية في التطبيق. المفتاح العام فقط عبر `--dart-define` أو GitHub Secrets.
